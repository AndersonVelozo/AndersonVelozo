### 🚀 Projetos em Destaque

#### 💰 [Finance.ai - Gestão Financeira Inteligente](https://github.com/AndersonVelozo/Finance.ai)
> Plataforma web completa para controle financeiro pessoal com insights gerados por IA

**Stack:** Next.js 14, TypeScript, Prisma, PostgreSQL, TailwindCSS  
**Features:**
- 💳 Controle completo de receitas, despesas e investimentos
- 📊 Dashboards interativos com gráficos em tempo real
- 🎯 Sistema de metas financeiras e planejamento de orçamento
- 📈 Análise detalhada de gastos por categoria e período
- 🤖 **Recomendações inteligentes geradas por IA**
- 🔐 Autenticação segura com Clerk

🔗 **[Ver projeto ao vivo](https://finance-ai-eosin-zeta.vercel.app)**

---

#### 🛒 [JáComprou - Comparador de Preços Inteligente](https://github.com/AndersonVelozo/jacomprou)
> Plataforma que compara preços de supermercados em tempo real com web scraping automatizado

**Stack:** React Native, Python (FastAPI + Playwright), PostgreSQL, Redis, Expo  
**Features:**
- 🗺️ Mapa interativo com **Mapbox** mostrando preços em tempo real
- 📍 Localização geográfica e busca por proximidade (raio de 5km)
- 📊 Analytics de ROI (economia vs custo de deslocamento)
- 📱 PWA instalável (funciona offline)
- 🔔 Sistema de notificações push
- 🎯 Pins pulsantes para preços atualizados recentemente

**Arquitetura:**
- Backend API (FastAPI + PostgreSQL)
- Serviço de scraping modular com retry automático
- App mobile nativo (React Native + Expo)
- PWA para instalação direta no smartphone

#### 🏥 [Clínica - Sistema de Gestão Hospitalar Completo](https://github.com/AndersonVelozo/Clinica)
> Sistema full stack para gestão de clínicas médicas com app mobile para pacientes

**Stack:** Next.js, TypeScript, React Native, Expo, Prisma, PostgreSQL  
**Features:**
- 📅 **Agendamento online** de consultas com disponibilidade em tempo real
- 👨‍⚕️ Painel administrativo para médicos e recepcionistas
- 📱 **App mobile para pacientes** (iOS e Android)
- 📋 Prontuário eletrônico completo
- 💉 **Cartão de vacinas digital**
- 🩺 Monitoramento de pacientes crônicos (glicemia, pressão arterial)
- 🔔 Sistema de notificações push
- 🔒 Segurança e privacidade (LGPD compliant)
- 📊 Relatórios e analytics médicos
- 💊 Prescrições digitais

**Arquitetura:**
- Frontend web (Next.js 14 + TypeScript)
- Backend API (Next.js API Routes)
- App mobile nativo (React Native + Expo)
- Banco de dados relacional (PostgreSQL + Prisma)
- Autenticação segura e gerenciamento de sessões
